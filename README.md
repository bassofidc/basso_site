# bassofidc.com.br

Site institucional da Basso FIDC, publicado pelo GitHub Pages a partir da branch `main`.

## Estrutura

| Caminho | O que é |
|---|---|
| `index.html` | Página única do site (HTML, CSS e JS no mesmo arquivo) |
| `logos/` | Logos de parceiros usados no site |
| `fotos_escritorio/` | Fotos das unidades (`bc_` = Balneário Camboriú, `pf_` = Passo Fundo) |
| `area_cliente/` | Instalador do Remessa Qprof (link "Área do cliente") |
| `assinaturas/` | **Imagens das assinaturas de e-mail. Não renomear, mover nem apagar.** |
| `CNAME` | Domínio do Pages (`bassofidc.com.br`) |

## Atenção: assinaturas de e-mail

As assinaturas carregam as imagens direto do site, por exemplo
`http://www.bassofidc.com.br/assinaturas/basso/logo.png`.
Qualquer mudança de nome ou pasta quebra a imagem em todos os e-mails já enviados.
Para trocar uma imagem, substitua o arquivo mantendo o mesmo nome.

## Como atualizar

Edite os arquivos, faça commit na `main` e dê push. O Pages publica em 1 a 2 minutos.
